# Gunshade // Co-op

Сетевая двухигровая версия Gunshade на основе прикреплённого `gunshade_lev_edisen.html`. Это top-down кооперативный шутер для Render: второй игрок подключается к той же странице, и общий мир запускается автоматически.

## Сохранённые главные механики

- карта со стенами и столкновениями;
- два игрока в одном мире;
- HP и состояние смерти;
- враги, обнаружение, преследование и атака;
- пистолет с патронами и перезарядкой;
- нож с cooldown и ближней атакой;
- базука после подбора ракеты;
- лечение, броня и подбор предметов;
- кровь: постоянные кровавые пятна, брызги, кровавый фонтан после убийства ножом, взрывы и hit effects;
- серверная синхронизация игроков, врагов, пуль, предметов и состояния боя;
- автоматический режим ожидания второго игрока и экран поражения.

## Управление

### Клавиатура и мышь

- `WASD` или стрелки — движение.
- Мышь — прицел.
- Левая кнопка мыши — огонь / удар.
- `Q` — смена оружия.
- `E` — подобрать аптечку, броню или базуку.

### Телефон

- левый виртуальный джойстик — движение;
- правая область — `FIRE`, смена оружия и подбор предметов;
- интерфейс рассчитан на landscape и portrait, но для карты удобнее landscape.

## Запуск локально

```bash
npm install
npm start
```

Откройте `http://localhost:10000` в двух вкладках или на двух устройствах в одной доступной сети.

Проверки:

```bash
npm test
```

## Render

Архив уже содержит `render.yaml`:

1. Загрузите проект в GitHub.
2. В Render нажмите **New → Web Service**.
3. Подключите репозиторий.
4. Оставьте настройки из `render.yaml` или используйте:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Health Check Path: `/health`
5. Откройте одну Render-ссылку в двух браузерах/устройствах.

Сервер слушает `0.0.0.0` и использует Render-переменную `PORT`. WebSocket подключается через `wss://` на том же домене.

## Структура

- `server.js` — авторитетный игровой сервер и WebSocket-протокол.
- `public/index.html` — HUD и touch-интерфейс.
- `public/app.js` — canvas-рендер, управление и клиентская синхронизация.
- `public/styles.css` — интерфейс и мобильная раскладка.
- `reference/gunshade_lev_edisen.html` — исходный прикреплённый файл для сравнения.
